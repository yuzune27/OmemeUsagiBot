# OmemeUsagiBot 🐇

Discordで「ちいさな うさぎ」とおはなしできる会話Botです。あいさつや日々のできごとなど、気軽に話しかけると、絵文字を交えたやさしい口調でお返事します。

## ちいさな うさぎについて

明るくてやさしい、少し心配性なうさぎです。自転車で走ることや外で遊ぶことが大好きで、友達を大切にしています。ひらがな多めのやわらかい言葉で、ほのぼのとした会話を楽しめます。

## できること

- **チャンネルでおしゃべり**：設定したチャンネルに投稿すると返信します。毎回メンションやコマンドを付ける必要はありません。
- **会話の流れに合わせたお返事**：チャンネルの直近最大20件のメッセージを参考にして返信します。
- **日時を踏まえた会話**：現在の日付・曜日・時刻を参考に、時間帯や季節に合わせておはなしします。
- **名前を交えた会話**：サーバーでの表示名などを参考に、相手の名前を呼ぶことがあります。
- **Web検索を使ったお返事**：返信の生成時に、うさぎが必要に応じてWeb検索を利用できます。
- **サーバーごとの会話場所の設定**：うさぎと話すチャンネルを、サーバーごとに1つ選べます。
- **会話のリセット**：`/reset` で、それまでの会話をお返事の参考にしないようにして、新しくおはなしを始められます。

返信を考えている間は「入力中」と表示されます。長いお返事は複数のメッセージに分けて届きます。

## はじめかた

「ちいさな うさぎ」が参加しているサーバーで、次の操作を行います。

1. うさぎとおはなししたいテキストチャンネルを開きます。
2. `/set_channel` を実行します。
3. 設定完了のメッセージが表示されたら、そのチャンネルで話しかけてみましょう。

「おはよう」「今日はおさんぽしたよ」「がんばったからほめて」など、普段の会話と同じように投稿できます。

「今日は何曜日」「もう夜だね」「秋は何をして遊ぼう」など、日時や季節にまつわる話題も話しかけてみてください。

## コマンド

| コマンド | 機能 |
| --- | --- |
| `/set_channel` | 実行したチャンネルを、そのサーバーでの会話場所に設定します。 |
| `/reset` | 会話をリセットするための確認を表示します。会話場所に設定されたチャンネルで使えます。 |

会話場所を変更したいときは、移動先のチャンネルで再び `/set_channel` を実行してください。それまでのチャンネルでは返信しなくなります。サーバー内で使うコマンドのため、DMでは設定できません。

## 会話をリセットするには

話題を切り替えたいときや、それまでのやりとりを引き継がずに話したいときは、会話場所で `/reset` を実行してください。

1. 自分だけに見える確認メッセージが表示されます。
2. 「うん」を押すと、確認した時点までの会話をお返事の参考にしなくなります。
3. リセット完了のメッセージが表示されたら、新しく話しかけてください。「また今度」を押すと、リセットせずに会話を続けられます。

リセットは、そのチャンネル全体の会話に適用されます。実行した人とのやりとりだけを対象にするものではありません。Discord上のメッセージは削除されず、会話場所の設定やうさぎの性格・友達の設定も変わりません。

## 利用について

- 返信するのは、会話場所に設定されたチャンネルだけです。DMやBotアカウントの投稿には返信しません。
- 会話の参考にするのは直近最大20件です。昔の会話をずっと覚えているわけではありません。またリセット後は、その時点より後のメッセージだけを参考にします。
- 日時はうさぎが住んでいる環境の時刻を基準にします。利用者の地域によっては、現地の時刻と異なる場合があります。
- 返信はAIが生成します。内容に間違いが含まれることがあります。
- 返信の生成にはSakana AIを使用し、会話に使うメッセージ本文と表示名が送信されます。

## 返信が来ないとき

会話したいチャンネルで `/set_channel` を実行したか確認してください。うさぎがオフラインの場合や、チャンネルの閲覧・履歴の閲覧・メッセージ送信に必要な権限がない場合は、サーバー管理者に確認してください。
